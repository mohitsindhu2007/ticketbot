# ⚡ Phantom Tickets Bot

A professional Discord ticket management bot designed for gaming communities, offering advanced support interaction capabilities through intelligent and user-friendly interfaces.

## Key Components
- Discord.py bot framework
- Advanced ticket handling cogs
- Dynamic embed utility functions
- Intelligent link and interaction management
- File-based mutex system to prevent duplicate ticket creation
- Optimized for WispByte hosting

## Installation
1. Clone this repository
2. Install requirements with `pip install -r requirements.txt`
3. Configure your `.env` file with your Discord Bot Token
4. Run using `python main.py`

## WispByte Hosting Compatibility
This bot is specifically designed to work on WispByte hosting, with these features:
- Minimal Flask endpoint to keep the bot online
- File-based interaction locking to prevent duplicate processing
- Multi-instance awareness to prevent conflicts
- Optimized error handling for long-term stability
